WEEK 2 CSS FUNDAMENTALS - Gopal

Project: Personal Portfolio Website

FILES:
- index.html: Main webpage structure
- css/style.css: All styling, layout and responsive CSS

HOW TO RUN:
1. Extract the ZIP folder.
2. Open the WD_Week2_Gopal folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server".
   You can also open index.html directly in a browser.

TASK COVERAGE:
Task 1 - CSS syntax, external stylesheet, element/class/ID/universal
         selectors, colors, backgrounds, fonts and text alignment.
Task 2 - Width, height, margin, padding, border, border-radius,
         box-shadow, spacing and alignment.
Task 3 - Flex container/items, flex-direction, justify-content,
         align-items, gap and flex-wrap.
Task 4 - CSS Grid, rows, columns, gap and multiple-column layout.
Task 5 - Media queries for tablet and mobile screen sizes.
Task 6 - Complete responsive personal portfolio mini project.

BEFORE SUBMISSION:
- Replace or update any personal details if required.
- Test the website at desktop, tablet and mobile widths.
- Keep index.html and the css folder together.
- Upload the ZIP to Google Drive and set access to
  "Anyone with the link" as Viewer.
