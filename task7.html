Week 1 Reflection & Learning

My HTML Learning Experience

During Week 1 of my Web Development Internship, I learned the fundamentals of HTML5 and how to create structured web pages. I learned about HTML document structure, headings, paragraphs, text formatting, hyperlinks, images, lists, and tables.

I also learned how to create student registration forms using different input types such as text, email, radio buttons, checkboxes, date, and dropdown menus. Additionally, I understood the importance of semantic HTML tags like header, nav, main, section, article, and footer.

The most challenging topic for me was creating HTML forms and understanding the proper use of different input elements. However, practicing each concept helped me improve my understanding.

I enjoyed learning about hyperlinks, images, tables, and forms because these elements make websites more useful and organized.

HTML is the foundation of web development. It helps me understand webpage structure and will make it easier for me to learn CSS and JavaScript in the future.

Overall, this assignment improved my practical knowledge and increased my confidence in web development.
